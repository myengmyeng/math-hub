# 인수인계 — 퀴즈온 세트 만들기: 중3 원의 중심과 현의 길이 (45분)

컴퓨터에서 퀴즈온 세트를 만드는 사람(또는 Claude)이 이 문서만 보고 끝낼 수 있게 정리했어요.

- 세트 제목: **중3 · 원의 중심과 현의 길이**
- 빠르기 점수: **끔**
- 구성: 전시학습 4문항(1~4) → 증명 20장(5~24, 분석 포함) → 정리학습 문제(25번부터, **E의 규칙대로 직접 구성**)

문항 글은 퀴즈온에 그대로 붙이면 되도록 일반 글자(√, ⊥, ∠)로 썼어요.

---

## A. 전시학습 (10분) — 지난 퀴즈에서 4문항 복사

원본: 지난 시간 **현의 수직이등분선 퀴즈(26문항짜리)**.
퀴즈온의 문항 복사 기능으로 아래 4문항을 **새 세트 맨 앞(1~4번)**에 가져와요.
- 도입 슬라이드는 넣지 않아요. 전시학습은 이 4문항뿐이에요.
- 그림·보기·정답·유형·배점·라운드는 원본 그대로 두고, **시간만 바꿔요.**

| 새 번호 | 원본 번호 | 유형 | 내용 | 정답 | 바꿀 것 |
|---|---|---|---|---|---|
| 1 | **11번** | 선택형 · 500점 | AB = 12 cm일 때 AM | 6 cm (2번째 보기) | 시간 180초 → **30초** |
| 2 | **13번** | 단답형 · 1000점 | AM = 7 cm일 때 AB | 14 | 시간 → **30초** |
| 3 | **18번** | 단답형 · 1000점 · 역전 라운드 | AB = 24, OM = 5일 때 x(반지름) | 13 | 시간 → **60초** |
| 4 | **21번** | 단답형 · 1000점 | 반지름 10, 거리 6일 때 x(현) | 16 | 시간 → **60초** |

해설 칸이 비어 있으면 아래를 붙여 넣어요.
- 1: 수선은 현을 이등분 → AM = 12 ÷ 2 = 6 cm
- 2: AB = 2 × AM = 14 cm
- 3: AM = 12, OM = 5 → x = √(12² + 5²) = 13 (반지름이 빗변)
- 4: 현의 절반 = √(10² − 6²) = 8 → x = 16

## B. 증명 (약 23분) — 새로 입력할 20장 (5~24번)

🖼 = 넣을 그림 (C의 목록) · 🔎분석 = 결론에서 거꾸로 올라가는 분석 단계

흐름: 성질마다 **가정·결론 확인 → 🔎 분석(결론이 성립하려면 무엇이 먼저 참이어야 하나, 가정에 닿을 때까지 거꾸로) → 증명(분석의 역순으로 앞으로 내려가며 쓰기) → 📦 결론 박스**

**5 · 슬라이드**
🔍 오늘의 질문 — 한 원에서 중심까지의 거리가 같은 두 현은 길이도 같을까? 거꾸로, 길이가 같은 두 현은 중심에서의 거리도 같을까?

**6 · 슬라이드** 🖼 `1-성질1-그림.png`
성질 ① — 원 O에서 OM ⊥ AB, ON ⊥ CD일 때, OM = ON이면 AB = CD이다.

**7 · 선택형 · 30초 · 1000점**
성질 ①에서 가정은?
보기: AB = CD / **OM = ON** ✔ / OA = OC / AM = CN
해설: 가정: OM = ON (주어진 것) · 결론: AB = CD (보일 것)

**8 · 슬라이드** 🔎분석 🖼 `1-성질1-그림.png`
🔎 거꾸로 생각하기 — 결론 AB = CD에서 출발! AB = CD가 되려면 무엇이 먼저 참이어야 할까?

**9 · 선택형 · 30초 · 1000점** 🔎분석
AB = CD가 되려면 먼저 무엇이 같으면 될까? (M, N은 수선의 발)
보기: **AM = CN** ✔ / OA = OC / AM = MB / ∠OAM = ∠OCN
해설: 수선은 현을 이등분(전시학습 성질!) → AB = 2AM, CD = 2CN. 그래서 AM = CN만 보이면 AB = CD

**10 · 선택형 · 30초 · 1000점** 🔎분석
그럼 AM = CN이 되려면 무엇을 보이면 될까?
보기: AB ⊥ CD / AM = MB / **△OAM ≡ △OCN** ✔ / OA = OB
해설: AM, CN을 한 변으로 갖는 두 삼각형이 합동이면 대응변으로 AM = CN

**11 · 슬라이드** 🔎분석 🖼 `7-분석-성질1.png`
🔎 거꾸로 올라온 길 — AB = CD ⇐ AM = CN ⇐ △OAM ≡ △OCN ⇐ ? 합동을 보이려면 먼저 두 삼각형이 있어야 해. 어떤 선을 그을까?

**12 · 슬라이드** 🖼 `2-성질1-증명.png`
증명 ① — 이제 앞으로 내려가며 써 보자. 반지름 OA, OC를 그으면 두 직각삼각형 △OAM, △OCN이 생긴다.

**13 · 선택형 · 30초 · 1000점**
△OAM과 △OCN에서 OA = OC인 이유는?
보기: 가정 / **원의 반지름** ✔ / 공통인 변 / 맞꼭지각
해설: OA, OC는 모두 원 O의 반지름 → 빗변(H)이 같다

**14 · 슬라이드** 🖼 `2-성질1-증명.png`
증명 ② — △OAM과 △OCN에서 ∠OMA = ∠ONC = 90° · OA = OC (반지름) · OM = ON (가정)

**15 · 단답형 · 30초 · 1000점 · 2배 라운드**
△OAM ≡ △OCN이다. 어떤 합동 조건일까? (영문 3글자)
정답: RHS, RHS합동
해설: 직각(R) · 빗변 OA = OC(H) · 한 변 OM = ON(S) → RHS 합동

**16 · 슬라이드** 🖼 `2-성질1-증명.png`
증명 ③ — 합동이므로 AM = CN. 수선은 현을 이등분하므로 AB = 2AM = 2CN = CD. 거꾸로 올라온 길을 그대로 내려왔다!

**17 · 슬라이드** 🖼 `4-결론박스-성질1.png`
📦 성질 ① — 원의 중심에서 같은 거리에 있는 두 현의 길이는 같다. (RHS 합동 → AM = CN → 2배)

**18 · 슬라이드** 🔎분석 🖼 `3-성질2-증명.png`
성질 ② (①의 역) — AB = CD이면 OM = ON이다. 🔎 이번에도 결론에서 거꾸로! OM = ON이 되려면 △OAM ≡ △OCN이면 된다. 그럼 합동이 되려면?

**19 · 선택형 · 30초 · 1000점** 🔎분석
△OAM ≡ △OCN (RHS)이 되려면 직각과 빗변(OA = OC) 말고 무엇이 같아야 할까?
보기: OM = ON / **AM = CN** ✔ / AB = CD / ∠OAM = ∠OCN
해설: S로 AM = CN이 필요. OM = ON은 우리가 보일 결론이라 근거로 쓰면 안 돼요!

**20 · OX · 20초 · 1000점** 🔎분석
AM = CN은 가정에서 얻을 수 있다: AM = ½AB = ½CD = CN
정답: O
해설: 수선은 현을 이등분 + 가정 AB = CD → AM = CN. 거꾸로 올라가다 가정에 도착!

**21 · 순서 · 60초 · 1000점 · 역전 라운드**
이제 앞으로! 성질 ②의 증명을 순서대로 놓아 보자
올바른 순서: 1. AM = ½AB = ½CD = CN  2. ∠OMA = ∠ONC = 90°, OA = OC (반지름)  3. △OAM ≡ △OCN (RHS 합동)  4. 대응변이므로 OM = ON
해설: 가정 → AM = CN → 직각·빗변 → RHS 합동 → OM = ON (분석의 역순)

**22 · 슬라이드** 🖼 `5-결론박스-성질2.png`
📦 성질 ② — 길이가 같은 두 현은 원의 중심에서 같은 거리에 있다. (AM = CN → RHS 합동 → OM = ON)

**23 · 슬라이드** 🖼 `6-결론박스-정리.png`
📦 정리 — 한 원에서 ① 중심에서 같은 거리에 있는 두 현의 길이는 같다. ② 길이가 같은 두 현은 중심에서 같은 거리에 있다.

**24 · 설문 · 20초 · 점수 없음**
짝에게 두 성질의 증명을 설명할 수 있나요?
보기: 자신 있다 / 대략 할 수 있다 / 합동 부분이 헷갈린다 / 아직 어렵다

## D. 정리학습 문제 (15분, 25번부터) — 받는 것

선생님이 문제 **캡처 사진**을 따로 줘요 (쉬운 교과서 문제 2개 · 교과서 심화 1개 · 내신 기출 1개 정도).
**배치, 유형, 그림, 배점, 라운드는 아래 E의 규칙대로 직접 정해서** 25번부터 넣어요. 선생님께 다시 묻지 않아도 돼요.
단, 캡처에서 정답을 확신할 수 없을 때만 선생님께 확인해요.

## E. 정리학습 문제 구성 규칙

### 1) 배치
- 맨 앞에 슬라이드 1장: "✏ 활용 — 성질을 문제에 써 보자. 풀이는 공책에, 답은 태블릿에!"
- 그다음 **쉬운 문제 → 어려운 문제** 순서 (교과서 기본 → 교과서 심화 → 내신 기출).
- 풀이 단계가 2개 이상인 기출은 **두 문항으로 나눠요.**
  - 1단계: 중간 결론을 묻는 선택형 (예: "어떤 삼각형일까?")
  - 2단계: 최종 답

### 2) 유형 고르기
| 답의 모양 | 유형 |
|---|---|
| 자연수·정수 하나 (길이, 각도) | **단답형**, 문제 끝에 "(※단위 없이 숫자만 입력할 것)" |
| √, 분수, 문자식, π가 들어간 답 | **선택형**. 오답 보기 3개는 흔한 실수로 만들기 (절반만 구함, 2배 안 함, 제곱 실수 등) |
| 성질이 맞는지 판단 | **OX** |
| 여러 답 중 고르기, 이유·근거 묻기 | **선택형** |

단답형 정답 칸에는 "8"과 함께 "8cm"도 넣어 두면 안전해요.

### 3) 그림
- 캡처에서 **그림 부분만 잘라서** 문항 그림으로 넣어요.
- 캡처 속 정답, 풀이, 학생 필기, 문제 번호는 잘라내요.
- 문제 글은 그림에서 옮겨 적어 문항 글로 써요 (√, ⊥, ∠, ² 그대로).

### 4) 시간 · 배점
| 수준 | 시간 | 배점 |
|---|---|---|
| 교과서 기본 | 60~90초 | 1000점 |
| 교과서 심화 | 180초 | 2000점 |
| 기출 1단계 | 60초 | 1000점 |
| 기출 2단계 (마지막 문항) | 180초 | 1000점 + 파이널 베팅 |

- 빠르기 점수는 끈 상태 그대로 둬요.
- 해설 칸에는 풀이 한두 줄과 근거가 되는 성질(①/②)을 적어요.

### 5) 라운드 ⚠ 중요
- **파이널 베팅은 세트의 맨 마지막 점수 문항 하나에만** 넣어요.
  - 점수가 들어가는 마지막 문항의 **바로 앞 문항에는 절대 넣지 않아요.** 베팅으로 점수를 잃은 직후에 마지막 문제를 풀게 되면 학생들이 기가 죽어요.
  - 마지막 문항 뒤에는 점수 없는 슬라이드나 설문만 와도 괜찮아요.
- **2배 라운드는 교과서 심화 1문항에만** 넣어요.
- **역전 라운드는 쓰지 않아요.** 증명 파트(21번)에서 이미 썼고, 마지막 베팅이 역전 기회 역할을 해요.
- 번개, 룰렛 라운드는 쓰지 않아요.
