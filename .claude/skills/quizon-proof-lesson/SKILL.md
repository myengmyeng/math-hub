# 퀴즈온 증명 활동 구조화 틀

선생님(중학교 수학)이 증명을 퀴즈온으로 진행할 때, **증명 파트**를 만드는 규칙이에요.
이 규칙대로 정하고, 정답이 확실하지 않거나 원본 증명이 없을 때만 선생님께 물어요.
세트의 앞뒤(전시학습, 정리학습)는 이 스킬의 범위가 아니에요.

## 0. 먼저 받을 것

| 받을 것 | 없을 때 |
|---|---|
| 증명할 성질(정리) 문장 | 물어요 |
| 교과서의 증명 설명 (사진·글) | 교과서 표준 증명으로 쓰고, 그렇게 썼다고 알려요 |
| 이 수업 전에 배운 성질 (근거로 쓰일 것) | 교과서 단원 순서로 짐작하고 알려요 |

## 1. 증명 파트 구조

```
오늘의 질문 (슬라이드)
→ 성질마다:
   성질 소개 + 그림 (슬라이드)
   → 가정 고르기 (선택형) — 가정·결론을 분명히
   → 🔎 분석: 결론에서 거꾸로 "이것이 참이려면 무엇이 먼저 참이어야 하나?"를 가정에 닿을 때까지
   → 증명(종합): 분석의 역순으로 앞으로 내려오며, 증명 슬라이드와 끊어 묻기 반복
   → 📦 결론 박스 (슬라이드)
→ 📦 성질 ①·② 종합 정리 박스 (성질이 2개 이상일 때)
→ 설문 "짝에게 설명할 수 있나요?" (점수 없음)
```

- 빠르기 점수는 **끔** (증명은 생각하는 활동이에요).
- 두 번째 성질이 첫 번째의 **역**이면, 학생이 완성하는 흐름으로 짜요:
  성질 소개 + 분석 시작(가정·결론이 바뀐 것 강조) → 분석 문항(바뀐 조건) → 가정에 닿는 OX → 증명 단계 **순서 배열**(분석의 역순) → 결론 박스.
- 성질 하나는 대략 슬라이드 5~6장 + 문항 4~5개 (약 10~12분)예요.

## 1-1. 🔎 분석 단계 (모든 성질에 넣기)

가정과 결론을 확인한 **바로 다음**, 증명을 쓰기 **전에** 넣어요.

- **시작 슬라이드:** "🔎 거꾸로 생각하기 — 결론 ○○에서 출발! ○○이 되려면 무엇이 먼저 참이어야 할까?" (성질 소개 그림 재사용)
- **분석 문항 (선택형, 한 칸에 1문항):** "○○이 되려면 먼저 무엇이 같으면 될까?" → 다음 칸 → … 가정이나 이미 아는 사실에 닿을 때까지.
  - 오답 보기: **참이지만 결론과 연결되지 않는 것** (예: AM = MB), 엉뚱한 조건.
  - 역 성질에서는 **결론 자체를 보기에 넣어요** (예: OM = ON). 해설: "우리가 보일 결론이라 근거로 쓰면 안 돼요" → 순환논리 짚기.
- **분석 사다리 그림 (슬라이드):** 결론(맨 아래, 파랑) ⇑ 칸 ⇑ 칸 ⇑ "?"(빨간 점선). 화살표 옆에 "무엇이 참이면 될까?"와 근거.
  - **뒤에서 물을 내용(합동 조건 등)은 사다리에 쓰지 않고 "?"로 둬요.**
  - 사다리 끝("?")이 **보조선이 필요한 이유**가 되게 해요 (예: "합동을 보이려면 두 삼각형부터!").
- 가정에 닿는 순간을 OX로 확인해요 (예: "AM = CN은 가정에서 얻을 수 있다: AM = ½AB = ½CD = CN").
- **증명 첫 슬라이드:** "이제 앞으로 내려가며 써 보자" — 증명 = 분석의 역순이라는 것을 문구로 밝혀요. 마지막 증명 슬라이드에 "거꾸로 올라온 길을 그대로 내려왔다!".
- 판서: 칠판 양 끝에 가정·결론을 적고, 분석은 결론 쪽에서 가정 쪽으로 사다리를 쌓고(⇑), 증명은 그 옆에 ⇓로 내려오며 칸마다 ✔.

## 2. 교과서 증명 → 페이지 대응

| 교과서 요소 | 페이지 | 유형 |
|---|---|---|
| 도입 질문 ("항상 그럴까?") | 오늘의 질문 | 슬라이드 |
| 성질 문장 | 성질 소개 + 그림 | 슬라이드 |
| "~이면 ~이다" | 가정 고르기 | 선택형 |
| (교과서에 없음) 결론에서 거꾸로 | 🔎 분석 시작 · 분석 문항 · 분석 사다리 | 슬라이드 / 선택형 / 슬라이드(그림) |
| 보조선 | 증명 ① | 슬라이드 |
| 각 줄의 (근거) | 끊어 묻기 | 선택형 / OX |
| 핵심 근거 (합동 조건 등) | 끊어 묻기 (핵심) | 단답형 · **2배 라운드** |
| 앞에서 배운 성질이 근거로 쓰이는 줄 | "이 근거는?" | 선택형 (해설에 "지난 시간 성질!") |
| 결론 | 📦 결론 박스 | 슬라이드 (그림) |
| 역 증명의 전체 흐름 | 순서 배열 | 순서 · **역전 라운드** |

### 끊는 규칙
- **핵심 근거가 나오기 바로 앞 줄에서** 끊어요. 학생이 다음 줄을 예측하게 하고, 공개 화면이 다음 슬라이드로 이어지게 해요.
- 슬라이드 하나에는 증명 한두 줄만 넣어요.
- 보조선 슬라이드는 분석 사다리의 "?" 바로 뒤에 와요. "어떤 선을 그으면 될까?"를 먼저 묻고 보여 줘요.
- 분석 문항에서 이미 다룬 근거(예: 수선은 현을 이등분)는 증명 파트에서 다시 묻지 않아요. 슬라이드 문구로만 확인해요.

### 문항 만드는 규칙
- 선택형 오답 보기는 **실제로 헷갈리는 것**으로 만들어요.
  - 가정 ↔ 결론
  - 반지름 ↔ 공통변 ↔ 가정
  - SAS ↔ RHS ↔ RHA ↔ ASA
  - "합동이라서" ↔ 앞에서 배운 성질
- 합동 조건 단답은 정답 칸에 변형도 넣어요 (RHS, RHS합동).
- 해설 칸에는 근거 한 줄을 적어요 (공개 화면에서 판서로 짚는 용도).
- 퀴즈온에 넣는 글은 일반 글자로 써요 (√, ⊥, ∠, °, ½, ≡). 수업 허브 JSON이면 `$…$` 수식을 써도 돼요.

## 3. 시간 · 배점 · 라운드

| 문항 | 시간 | 배점 | 라운드 |
|---|---|---|---|
| 가정 고르기, 근거 고르기, 분석 문항 | 30초 | 1000 | – |
| OX | 20초 | 1000 | – |
| 핵심 근거 (합동 조건 등) | 30초 | 1000 | **2배** (성질 하나에 1문항만) |
| 역 증명 순서 배열 | 60초 | 1000 | **역전** |
| 설문 | 20초 | – | – |
| 슬라이드 | – | – | – |

- 번개, 룰렛, 파이널 베팅은 증명 파트에 쓰지 않아요.

## 4. 그림 규칙

- 도형은 **비스듬하게** 그려요 (대칭·평행으로 보이지 않게).
- 두 선분(현 등)은 **서로 만나지 않게**, 끝점끼리도 멀리 떨어지게 그려요.
- 도형을 **왼쪽에 몰고 오른쪽을 비워요** (판서 자리). 900×520 비율.
- 표시는 **가정만** 해요. 결론은 표시하지 않아요.
  - 성질마다 가정이 다르면 **그림을 따로** 만들어요. 예: 성질 ①(가정 OM = ON)은 OM·ON에 같은 눈금, 역인 성질 ②는 OM = ON 눈금을 지운 그림.
  - **바로 뒤 문항에서 물을 내용은 그 앞 슬라이드 그림에 표시하지 않아요.** 예: 성질 ② 다음 OX가 "AM = ½AB = ½CD = CN"을 물으면, 성질 ② 그림에 현의 절반 눈금(〃)을 넣지 않아요. 눈금은 문항 공개 뒤 판서로 그려요.
- 증명용 그림: 보조선(반지름 등)을 더하고, 합동시킬 두 삼각형에 같은 색 음영을 넣어요.
- 직각 표시는 작은 사각형, 같은 길이는 빨간 눈금으로 표시해요.

### 결론 박스
- **성질마다 1장 + 종합 정리 1장**
- 파란 테두리 박스, 제목 "📦 성질 ①"
- 내용: 성질 문장(굵게) + 식(가정 ⟹ 결론) + **회색 근거 한 줄** + 오른쪽 작은 그림
  - 회색 근거 줄 예: "근거: RHS 합동 → AM = CN → AB = 2AM = 2CN = CD"
- 종합 정리 박스: 성질 ①·② 문장과 식 두 줄, 작은 그림(눈금 없음). 화살표 방향만 바뀐 것이 보이게 나란히 놓아요.
- 그림 생성 참고 스크립트: math-hub 저장소 `세트/그림/만들기.js` (Playwright로 SVG → PNG)

## 5. 발문 원칙 (슬라이드·문항 설계에 반영)

- 슬라이드에서 판서로 설명하고, 바로 뒤 문항으로 확인하는 리듬.
- 보조선과 다음 단계는 교사가 먼저 말하지 말고 **질문으로 끌어내요.** 그래서 질문 슬라이드 다음에 답이 나오게 배치해요.
- 핵심 근거 문항의 공개 화면에서 가장 많은 오답 하나를 골라 "왜 이건 아닐까?"를 짚을 수 있게, 그 오답을 보기에 꼭 넣어요.
- 결론 박스는 다 같이 읽고, 회색 근거 줄을 짚으며 3단계로 요약해요.
- 설문 결과가 나쁘면 핵심 근거 슬라이드로 돌아가 2분 다시 짚어요.
