# 퀴즈온 증명 수업 만능틀

선생님(중학교 수학)이 증명 수업을 퀴즈온으로 진행할 때의 규칙이에요.
**선생님께 묻지 말고 이 규칙대로 정해요.** 정답을 확신할 수 없을 때, 원본 자료가 없을 때만 물어요.

## 0. 먼저 받을 것

| 받을 것 | 없을 때 |
|---|---|
| 단원·학년, 증명할 성질(정리) 문장 | 물어요 |
| 교과서의 증명 설명 (사진·글) | 교과서 표준 증명으로 쓰고 그렇게 썼다고 알려요 |
| 전시학습 문항 = **선생님이 고른 지난 퀴즈 문항** | 선생님이 고를 때까지 비워 둬요. 직접 새로 만들지 않아요 |
| 정리학습 문제 캡처 | 받으면 4장의 규칙대로 구성 |
| 수업 시간 배분 | 기본: 전시 10분 · 증명 20분 · 정리 15분 |

## 1. 세트 전체 구조

```
전시학습 (지난 퀴즈 문항만, 도입 슬라이드 없음)
→ 증명 파트: 성질마다 [질문 → 성질 소개 → 가정 묻기 → 증명 슬라이드와 끊어 묻기 → 📦 결론 박스]
→ 📦 성질 ①·② 정리 박스 (성질이 2개 이상일 때)
→ 설문 "짝에게 설명할 수 있나요?" (점수 없음)
→ 정리학습 (안내 슬라이드 1장 + 캡처 문제)
```

- 빠르기 점수는 **끔** (증명은 생각하는 활동이에요).
- 성질이 서로 **역** 관계면(예: ①의 역이 ②), 두 번째 성질은 **학생이 완성**하는 흐름으로 짜요: 소개 슬라이드 → 바뀐 조건(S 등)을 묻는 OX → 증명 단계 **순서 배열** → 결론 박스.

## 2. 증명 파트 만드는 법

### 교과서 → 페이지 대응
| 교과서 요소 | 페이지 | 유형 |
|---|---|---|
| 도입 질문 ("항상 그럴까?") | 오늘의 질문 | 슬라이드 |
| 성질 문장 | 성질 소개 + 그림 | 슬라이드 |
| "~이면 ~이다" | 가정 고르기 | 선택형 |
| 보조선 | 증명 ① | 슬라이드 |
| 각 줄의 (근거) | **끊어 묻기** | 선택형 / OX |
| 핵심 근거 (합동 조건 등) | 끊어 묻기 (핵심) | 단답형 · **2배 라운드** |
| 전시학습 성질이 근거로 쓰이는 줄 | "이 근거는?" | 선택형 (해설에 "전시학습 성질!") |
| 결론 | 📦 결론 박스 | 슬라이드 (그림) |

- **자르는 위치:** 핵심 근거가 나오기 바로 앞 줄에서 끊어요. 학생이 다음 줄을 예측하게 하고, 공개 화면이 다음 슬라이드로 이어지게 해요.
- 슬라이드 하나에는 증명 한두 줄만 넣어요.
- 선택형 오답 보기는 실제로 헷갈리는 것으로 만들어요 (가정 ↔ 결론, 공통변 ↔ 반지름, SAS ↔ RHS, RHA ↔ RHS).
- 해설 칸에는 근거 한 줄을 적어요 (공개 화면에서 판서로 짚는 용도).

### 시간·배점 (증명 파트)
- 끊어 묻기: 20~30초 · 1000점, 순서 배열: 60초 · 1000점
- 2배 라운드: **핵심 근거 1문항**에만
- 역전 라운드: 두 번째 성질의 **순서 배열**에만

## 3. 그림 규칙

- 원·삼각형 등은 **비스듬하게** 그려요 (대칭·평행으로 보이지 않게).
- 두 현(두 선분)은 **서로 만나지 않게**, 끝점끼리도 멀리 떨어지게 그려요.
- 그림은 **왼쪽에 몰고 오른쪽을 비워요** (판서 자리). 900×520 비율.
- 표시는 **가정만** 해요. 결론은 표시하지 않아요.
  - 성질 ①(가정 OM = ON): OM·ON에 같은 눈금
  - 성질 ②(가정 AB = CD): OM = ON 눈금을 **지우고** 현의 절반들에 같은 눈금(〃) → 그래서 **성질마다 그림을 따로** 만들어요
- 증명용 그림: 보조선(반지름 등)을 더하고, 합동시킬 두 삼각형에 같은 색 음영을 넣어요.
- **결론 박스는 성질마다 1장 + 종합 정리 1장**:
  - 파란 테두리 박스, 제목 "📦 성질 ①"
  - 성질 문장(굵게) + 식(가정 ⟹ 결론) + **회색 근거 한 줄**(예: "근거: RHS 합동 → AM = CN → AB = 2AM = 2CN = CD") + 오른쪽 작은 그림
  - 종합 정리 박스: 성질 ①·② 문장과 식 두 줄, 작은 그림(눈금 없음)
- 그림 생성 참고 스크립트: math-hub 저장소 `세트/그림/만들기.js` (Playwright로 SVG → PNG)

## 4. 정리학습(활용 문제) 구성 규칙

선생님이 문제 캡처를 주면 **배치·유형·그림·배점·라운드를 직접** 정해요.

### 배치
- 맨 앞에 슬라이드 1장: "✏ 활용 — 성질을 문제에 써 보자. 풀이는 공책에, 답은 태블릿에!"
- **쉬운 문제 → 어려운 문제** (교과서 기본 → 교과서 심화 → 내신 기출)
- 풀이가 두 단계 이상인 기출은 두 문항으로 나눠요: 1단계(중간 결론을 묻는 선택형) → 2단계(최종 답)

### 유형
| 답의 모양 | 유형 |
|---|---|
| 자연수·정수 하나 (길이, 각도) | 단답형 + 문제 끝에 "(※단위 없이 숫자만 입력할 것)" · 정답 칸에 "8", "8cm"처럼 변형도 |
| √, 분수, 문자식, π가 들어간 답 | 선택형 (오답 3개 = 흔한 실수: 절반만 구함, 2배 안 함, 제곱 실수) |
| 성질이 맞는지 판단 | OX |
| 고르기, 이유·근거 | 선택형 |

### 그림
- 캡처에서 **그림만 잘라** 넣어요. 정답·풀이·필기·문제 번호는 지워요.
- 문제 글은 옮겨 적어요. 퀴즈온은 일반 글자로 써요 (√, ⊥, ∠, °, ², ½).

### 시간·배점
| 수준 | 시간 | 배점 |
|---|---|---|
| 교과서 기본 | 60~90초 | 1000 |
| 교과서 심화 | 180초 | 2000 + **2배 라운드** |
| 기출 1단계 | 60초 | 1000 |
| 기출 2단계 = 마지막 점수 문항 | 180초 | 1000 + **파이널 베팅** |

## 5. 라운드 규칙 ⚠

- **파이널 베팅은 세트의 맨 마지막 점수 문항 하나에만** 넣어요.
  - 점수가 들어가는 마지막 문항의 **바로 앞 문항에는 절대 넣지 않아요.** 베팅으로 점수를 잃은 직후에 마지막 문제를 풀면 학생들이 기가 죽어요.
  - 마지막 점수 문항 뒤에는 점수 없는 슬라이드·설문만 와도 괜찮아요.
- 2배: 증명의 핵심 근거 1문항 + 정리학습 심화 1문항
- 역전: 두 번째 성질의 순서 배열 1문항 (전시학습 원본 문항에 이미 있으면 그대로 둬요)
- 번개·룰렛은 쓰지 않아요.

## 6. 전시학습 규칙

- **선생님이 보낸(고른) 지난 퀴즈 문항만** 써요. 새로 만들거나 더하지 않아요 (RHS 복습 등도 추가 금지).
- 도입 슬라이드를 넣지 않아요.
- 원본의 그림·보기·정답·유형·배점·라운드는 그대로 두고, **시간만** 줄여요 (쉬운 것 30초, 계산 60초). 10분 안에 끝나게 해요.

## 7. 산출물

1. **세트** (퀴즈온 또는 수업 허브 JSON). 허브 JSON 형식은 저장소 `세트/*.json` 참고 (선택형 정답은 1부터, 수식은 `$…$`).
2. **인수인계 문서**: 문항마다 [번호 · 유형 · 시간 · 배점 · 라운드 · 문제 글 · 보기(정답 ✔) · 정답 · 해설 · 넣을 그림 파일]과 마지막 확인 목록. 예: `세트/중3-원의-현의-길이-인수인계.md`
3. **수업 컨닝페이퍼 PDF**: A4, **슬라이드 4~6장마다 한 쪽**
   - 쪽 머리: 번호 범위 · 제목 · 시간
   - 목표 상자 (이 구간에서 학생이 얻을 것)
   - 표: 번호/유형 · 화면과 정답(그림 썸네일) · 🗣 주요 발문 · ✏ 판서 · ⚠ 예상 오답과 대응
   - 쪽 아래: 전환 멘트 / 이 쪽의 핵심
   - 마지막 쪽: 정리학습 진행 루틴 + 문제 메모 칸
   - 예: `세트/컨닝페이퍼/중3-원의-현의-길이.html` → Playwright `page.pdf`로 출력

## 8. 진행 원칙 (컨닝페이퍼에 녹일 것)

- 슬라이드에서 판서로 설명하고, 바로 뒤 문항으로 확인하는 리듬.
- 보조선·다음 단계는 교사가 먼저 말하지 말고 **질문으로 끌어내기**.
- 공개 화면의 **오답 분포**에서 가장 많은 오답 하나를 골라 "어디서 갈렸을까?"
- 결론 박스는 다 같이 읽고, 회색 근거 줄을 짚으며 3단계로 요약.
- 설문 결과가 나쁘면 핵심 근거 슬라이드로 돌아가 2분 다시 짚기.
